# pillar-6-demo

## Simple Calculator App

A command-line calculator application written in Python that performs basic arithmetic operations.

### Features

- **Addition**: Add two numbers
- **Subtraction**: Subtract one number from another
- **Multiplication**: Multiply two numbers
- **Division**: Divide one number by another (with zero-division protection)
- **Interactive Menu**: Easy-to-use command-line interface
- **Error Handling**: Robust error handling for invalid inputs

### Usage

Run the calculator app:

```bash
python calculator.py
```

### How to Use

1. Launch the calculator by running the command above
2. Select an operation from the menu (1-5)
3. Enter the first number when prompted
4. Enter the second number when prompted
5. View the result
6. Continue with more calculations or select option 5 to exit

### Example

```
========================================
Simple Calculator
========================================

Operations:
1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)
5. Exit
========================================

Select operation (1-5): 1
Enter first number: 10
Enter second number: 5

10.0 + 5.0 = 15.0
```

### Requirements

- Python 3.x
